# Tipografia local

- **Instrument Serif**: títulos editoriais, arquivos WOFF2 Regular e Italic, subset Latin. SIL Open Font License 1.1. Projetada por Rodrigo Fuenzalida com direção de Jordan Egstad, JD Hooge e Jack De Caluwé. [Projeto e licença](https://github.com/Instrument/instrument-serif).
- **DM Sans**: texto funcional, WOFF2 variável nos pesos 400–600, subset Latin. SIL Open Font License. [Repositório e licença](https://github.com/googlefonts/dm-fonts).

As fontes são servidas pelo próprio site; a página não solicita fontes a terceiros em tempo de execução. Os arquivos de licença completos estão nesta pasta.
